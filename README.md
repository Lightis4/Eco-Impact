🌱 EcoImpact — Pequenas atitudes, grandes mudanças

O EcoImpact é um site educativo que incentiva a sustentabilidade por meio de hábitos conscientes, desafios ecológicos e acompanhamento de ações sustentáveis. O objetivo é mostrar como pequenas mudanças na rotina podem contribuir para um futuro mais sustentável.

🎯 Objetivo do projeto

Promover a conscientização ambiental de forma interativa, ajudando os usuários a refletir sobre seus hábitos e descobrir maneiras de reduzir seus impactos no meio ambiente.

✨ Funcionalidades

- **Calculadora de hábitos sustentáveis:** responde a perguntas sobre hábitos cotidianos e recebe uma avaliação educativa.
- **Desafios ecológicos:** apresenta atividades práticas para incentivar atitudes sustentáveis.
- **Sistema de pontuação:** permite acumular pontos ao concluir desafios.
- **Painel de impacto pessoal:** acompanha a pontuação e o progresso do usuário.
- **Salvamento automático:** utiliza o `localStorage` do navegador para manter os dados salvos no dispositivo.
- **Interface responsiva:** adapta o layout para diferentes tamanhos de tela.
- **Navegação interativa:** facilita o acesso às principais áreas do site.

🛠️ Tecnologias utilizadas

- **HTML5:** estrutura e organização das páginas.
- **CSS3:** estilos, cores, layout e responsividade.
- **JavaScript:** interatividade, validação de formulários, pontuação e manipulação dos dados.
- **Bootstrap 5.3.3:** componentes e recursos para construção de uma interface responsiva.
- **Google Fonts:** tipografia utilizada na interface.
- **LocalStorage:** armazenamento dos dados diretamente no navegador.

## 🚀 Como executar o projeto

1. Clone o repositório:
   git clone https://github.com/Lightis4/Eco-Impact.git

2. Entre na pasta do projeto:
   cd Eco-Impact

3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server no Visual Studio Code.

Observação:o Bootstrap e as fontes externas precisam de conexão com a internet para serem carregados quando utilizados por CDN.

💾 Armazenamento de dados

O projeto utiliza o `localStorage`, recurso do navegador que permite armazenar informações localmente. Os dados permanecem disponíveis no mesmo navegador e dispositivo, mesmo após fechar e abrir a página novamente.

O sistema não utiliza banco de dados ou servidor para sincronizar as informações entre diferentes dispositivos.

🌍 Importância ambiental

O EcoImpact busca incentivar atitudes como economizar água e energia, reduzir o desperdício e adotar hábitos de consumo mais conscientes.

A pontuação apresentada possui finalidade educativa e não representa uma medição científica exata da pegada de carbono do usuário.
